# 목소리 비교 테스트 (2026-09-06)

새 수면 명상 채널의 나레이션 목소리를 정하기 위한 A/B/C 테스트.
근거: [../sleep-channel-concept.md](../sleep-channel-concept.md) §10

## 왜 이걸 먼저 하나
명상 나레이션은 **숨소리와 여백이 품질의 본체**다. 목소리가 어색하면 컨셉 전체가 죽는다.
12편을 만들고 나서 알게 되면 늦으므로, 1편 제작 전에 정한다.

## 공통 대본
`script_rainy_temple.txt` — 1번 소재 「비 오는 산사 처마 밑」의 도입 40초 분량.
문장 사이 빈 줄 = 실제 낭독에서 2~3초 정적. 이 여백을 살리느냐가 판정 기준이다.

## 판정 기준 (침대에 누워, 이어폰으로 듣는다)
1. **여백** — 문장 사이 정적이 어색하지 않은가 (기계가 "다음 줄로 넘어간다"는 느낌이 안 나는가)
2. **호흡** — 숨소리가 들리는가. 없으면 사람 목소리로 안 들린다
3. **끝맺음** — "…두세요"의 끝음이 떨어지며 잦아드는가, 아니면 또박또박 끊기는가
4. **졸림** — 30초 듣고 실제로 몸에 힘이 빠지는가
5. **반복 내성** — 같은 목소리를 매일 밤 들어도 질리지 않겠는가

## 산출물
오디오 파일은 커밋하지 않는다(용량·성격). 로컬에서만 듣고, 결과 판단만 아래에 기록한다.

| 안 | 설정 | 결과 |
|---|---|---|
| A. ElevenLabs 기본 | 야담 설정 그대로 (speed 1.0 / stability 0.5) | (미기록) |
| B. ElevenLabs 명상 튜닝 | speed 0.75 / stability 0.7 | (미기록) |
| C. Vrew | 현행 야담 워크플로 | (미기록) |
| D. 직접 녹음 | 폰 음성메모라도 무방 — 비교만 되면 된다 | (미기록) |

## 재현 명령
```bash
python scripts/tts/generate_tts.py docs/voice-test/script_rainy_temple.txt <출력폴더> \
  --config channels/yadam/config/settings.json --speed 0.75 --stability 0.7
```
