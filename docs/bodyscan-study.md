## 1. 바디스캔이란 무엇인가 — 기법 공부

### 1-1. 계보
- **원류**: 미얀마 위빠사나의 「스위핑(sweeping)」 수행(우 바킨 → 고엔카). 몸을 위에서 아래로 쓸어내리며 감각을 관찰.
- **현대화**: 1979년 존 카밧진(Jon Kabat-Zinn)이 매사추세츠대 병원에서 **MBSR**(마음챙김 기반 스트레스 완화)을 만들며 누워서 하는 핵심 수련으로 채택. 원본은 **45분**, **왼발 발가락에서 시작해 머리에서 끝난다**.
- **한국 유입**: 2000년대 MBSR 보급과 함께 "바디스캔"이라는 외래어 그대로 정착. 법보신문·UCLA 한국어판 등에서도 같은 용어.

### 1-2. 카밧진 원전의 순서 (Coming to Our Senses, 2005)
```
왼발 발가락 → 발바닥·뒤꿈치·발등 → 발목·정강이·종아리 → 무릎 → 허벅지 → 사타구니·왼 엉덩이
→ 오른발 (같은 순서) → 골반·엉덩이 → 허리 → 배 → 등 위·가슴·갈비·심장·폐 → 어깨뼈·쇄골·어깨
→ 팔 (양쪽 동시: 손가락 끝 → 손바닥·손등 → 손목 → 아래팔 → 팔꿈치 → 위팔 → 겨드랑이 → 어깨)
→ 목·목구멍 → 얼굴·머리
```
원전의 태도: "**affectionate, openhearted, interested attention**" — 감각을 바꾸려 하지 않고 **있는 그대로** 만난다.
통증이 더 또렷해질 수도 있는데 그것도 그냥 관찰. 이완은 목적이 아니라 **부산물**이다.
카밧진은 "몸을 악기라 치면 바디스캔은 조율, 집이라 치면 창문을 다 열어 환기하는 것"이라 비유했다.

### 1-3. 왜 잠이 오는가 — 기전
1. **주의의 독점**: 뇌가 한 번에 붙잡을 수 있는 주의는 한 줌이다. 그것을 「오른발 새끼발가락」 같은 아주 작은 곳에 묶으면 **반추(되새김)할 자원이 남지 않는다**. 잠 못 드는 밤의 본체는 "생각"이고, 바디스캔은 생각의 자리를 감각으로 밀어낸다.
2. **내수용감각(interoception) 활성 → 부교감 전환**: 몸 안 신호(무게·온도·맥동)에 주의를 두면 교감신경이 내려가고 부교감이 올라온다. "생각으로 이완하려는 게 아니라, **몸을 먼저 풀면 신경계가 따라온다**"는 방향.
3. **입면의 연습**: 잠은 "생각이 조각나며 흩어지는" 전환인데, 깬 채로 얕은 잠 상태를 흉내 내는 연습(NSDR/요가니드라)이 그 전환을 쉽게 만든다.
4. **날숨 = 이완 신호**: 들숨은 교감, 날숨은 부교감. 그래서 모든 수면용 대본이 "**내쉬는 숨에** 내려놓는다"고 말한다. 순서가 바뀌면 안 된다.

### 1-4. 네 가지 사촌 — 우리 대본이 어디에 서 있는지
| | MBSR 바디스캔 | **수면용 바디스캔** | 요가니드라(사티아난다) | 점진적 근이완(PMR) |
|---|---|---|---|---|
| 목적 | 알아차림(깨어 있기) | **잠들기** | 깬 채 깊은 이완 | 근육 이완 |
| 태도 | 관찰만. 바꾸지 않음 | 관찰 → **내려놓음** 허용 | 이름 부르면 즉시 이동, 분석 ✕ | 힘줬다 풀기 |
| 속도 | 느림 (45분) | **가장 느림, 정적이 절반** | 빠름 (부위당 3~5초, 61포인트) | 중간 |
| 순서 | 왼발→머리 | 발→머리 **또는** 머리→발 | 오른손 엄지→오른발→왼손→왼발→등→얼굴→몸통 | 손→팔→얼굴→몸통→다리 |
| 잠들면 | "실패"(깨어 있으라) | **"성공"** — 잠들라고 명시 | 원칙상 깨어 있으라 | 무관 |
| 끝 | 몸 전체 → 호흡 | **확언 → 완료 선언 → 소리만** | 결심(sankalpa) 반복 → 깨어남 | — |
| KO 대표 | 김주환(교수 해설형) | **에일린** | 요가소년 | 브레이너 제이(근이완 섞음) |

**우리는 2열(수면용)이다.** 수면용이 MBSR과 갈리는 지점 세 가지를 대본 규칙으로 못 박아야 한다:
(a) "잠들어도 됩니다"를 **말로 허락**한다, (b) 관찰에서 끝내지 않고 **내쉬는 숨에 내려놓는다**까지 간다, (c) 끝에 "깨어나라"가 없다 — 소리만 남기고 사라진다.

### 1-5. 원전이 주는 대본 재료 (아직 우리 v1.1에 없는 것)
- **"바꾸려 하지 마세요"** — 카밧진의 핵심 한 줄. "느껴지는 게 없어도 괜찮습니다. 없다는 것을 알아차리면 됩니다." (UCLA 한국어판: "숨을 잘 쉬는 방법은 없습니다")
- **감각의 어휘**: 무게 / 떨림 / 온도 / 맥동 / 옷이 닿는 느낌 / 공기가 닿는 느낌. 우리 대본은 「긴장」 한 단어만 쓴다. 어휘가 늘면 반복이 덜 지루하다.
- **접촉면 스캔**(요가소년 6:04~7:21): "머리와 바닥 사이 / 어깨와 바닥 사이 / …" — 몸이 아니라 **몸이 침대에 닿는 면**을 순회한다. 무게감·가라앉음 은유와 직결되고 잠에 특화된 진입로다.
- **무거움 → 가벼움 대비**(요가니드라 20:53~23:04): 온몸이 무거워져 가라앉다가 → 가벼워져 떠오른다. 입면 직전의 신체 이탈감을 그대로 유도한다.
- **뒤통수부터**(2024 에일린)는 베개에 닿은 첫 접촉면이라 자연스럽고, **발꿈치부터**(1,573만 에일린)는 "바닥과 닿아 있는 부분부터"라는 논리로 시작한다. 둘 다 접촉면에서 출발한다는 공통점.

### 3-2. 요가소년(237만)에서 가져올 것
- **접촉면 순회** (6:04~7:21, 9포인트): "머리와 바닥 사이 → 어깨와 바닥 사이 → 오른팔과 바닥 → 왼팔 → 등 → 엉덩이 → 오른다리 → 오른 발뒤꿈치 → 왼다리 → 왼 발뒤꿈치 → 몸 전체와 바닥"
- **"애써 잠을 자겠다는 마음을 비울수록 숙면에 가까워집니다"** (1:11) — 설명란에도 같은 문장. 역설적 의도(paradoxical intention)를 첫 1분에 심는다.
- 나레이션 뒤 **"검은 화면으로 약 3시간"** — 설명란에서 구성을 숫자로 밝힌다.

### 3-3. 브레이너 제이(6시간판 232만·2024)에서 가져올 것
- **챕터 13개**로 "지금 어느 단계인지"를 보여 준다: 도입 → 원리 → 마음챙김 → 바디스캔 근이완 → **사운드 조정 I** → … → 중력 명상 → **나레이션 없음** → **볼륨 점진 감소** → **화면 밝기 최저** → "기상알람 없음".
  즉 **소리·화면이 시간에 따라 어떻게 변하는지를 챕터로 약속**한다. 우리 2시간 편성(나레이션 → 백색소음 페이드인 → 검정)을 그대로 챕터로 쓸 수 있다.
- 설명란 「이용 권장 대상 / 추천 빈도 / 기대효과」 블록. 의료 검토 표기.

### 3-4. 공통점 — 조회수 나오는 바디스캔의 법칙 8
1. **제목 맨 앞은 편익, 기법명은 꼬리.** "N분만에 잠드는" > "꿀잠" > "수면유도 명상" ≫ "바디스캔".
2. **나레이션 10~15분 + 사운드 1~6시간.** 명상 단독 30분은 중위권 천장(김주환 37만). 총량은 사운드가 만든다.
3. **말은 적게, 정적은 길게.** 114자/분 이하. 8초 이상 정적이 40회 이상.
4. **접촉면에서 시작한다.** 뒤통수(베개)든 발꿈치(바닥)든 "지금 닿아 있는 곳"이 첫 부위. 그리고 그 이유를 한 문장으로 말해 준다.
5. **얼굴은 잘게(8곳), 몸통·다리는 굵게.** 얼굴 근육이 잠과 직결(눈꺼풀·턱·혀).
6. **감사 → 감정 거리두기 → 몸** 순서로 마음을 먼저 비운다. 자기 위로가 바디스캔 앞에 한 번, 뒤에 한 번.
7. **끝은 허락이다.** "잠들어도 됩니다 / 뭘 해도 좋습니다 / 이 소리가 아침까지" — 지시가 아니라 허락으로 닫는다. 확언은 3개 이내.
8. **썸네일에 누운 사람.** 16편 중 11편. 어두운 침실 실사(에일린 5편 전부) 또는 일러스트(브레이너). 텍스트는 편익 한 줄 + "수면 명상" 한 줄.

### 4-2. 대본 v2 제안 (v1.1 → 사용자 승인 후 반영)
v1.1의 뼈대(머리→발, 세 박자, 정적)는 맞다. 1,573만 편과 원전에서 **빠진 다섯 가지**만 넣는다:
1. **첫 문장에 상황 + 감사**: "오늘도 잠들기 전에, 이 소리를 켜 주셔서 감사합니다." (스마트폰 대신 → 우리는 그 표현을 피하고 같은 기능만)
2. **마음 구간을 「거리두기」로 교체**: "떠오르는 생각을 없애려 하지 않습니다. 그대로 두고, 그것에서 조금씩 멀어지는 나를 봅니다."
3. **바디스캔 안내 직전에 몸에 감사 한 문장**: "오늘 하루 이 몸이 저를 여기까지 데려다 주었습니다."
4. **접촉면 순회 1분 추가** (바디스캔 안내 뒤, 머리 구간 앞): "베개와 뒤통수 사이 → 침대와 어깨 사이 → 등 → 엉덩이 → 두 발꿈치 → 몸 전체와 침대 사이" — 6포인트, 각 8초 정적.
5. **끝의 허락 확장**: 확언 뒤에 "이제부터는 아무것도 하지 않아도 됩니다. 숨을 세어도, 처음부터 다시 몸을 돌아봐도, 그냥 소리를 들어도, 다 괜찮습니다."
   그리고 원전의 한 줄 — "**바꾸려 하지 않아도 됩니다. 느껴지지 않는 곳은 느껴지지 않는다는 것만 알면 됩니다.**" — 를 바디스캔 안내(§5)에.

발화량 +150~200자, 정적 +1분 → 약 13분. 여전히 에일린(15분)보다 짧다.

### 4-3. 편성 — 첫 6편 (1편 = 1작품, 제목이 서로 다르게)
| # | 제목 앞부분(편익) | 변주 축 | 길이 |
|---|---|---|---|
| 1 | 10분 안에 잠드는 꿀잠 수면유도 명상 | v2 기본 (머리→발) | 2h |
| 2 | 생각이 많아 잠 못 드는 밤을 위한 수면명상 | 마음 거리두기 구간 확장 | 2h |
| 3 | 내일 아침까지 깨지 않는 깊은 잠 | 접촉면 순회 + 무거움→가벼움 | 3h |
| 4 | 5분이면 됩니다 — 짧은 바디스캔 수면명상 | 나레이션 6분 압축판 | 1h |
| 5 | 낮잠·쪽잠 20분 회복 명상 | 요가니드라식 빠른 순회 + 알람 있음 | 20m |
| 6 | 1편 재편성 | 같은 나레이션 + 백색소음 6시간 | 6h |
길이 다변화(1h/2h/3h/6h)는 sleep-healing-benchmark §5-4의 "재편성으로 편수를 번다"를 그대로 쓴다.

### 4-4. 하지 않을 것
- 제목 앞에 「바디스캔」. 「치료」「불면증 치료」(면책 리스크 + 자극 카피).
- 30분 명상 단독 업로드(사운드 없이). 김주환형 천장.
- 브레이너식 권위 뱃지·굵은 컬러 텍스트. 우리 톤이 아니고, 실존 강사 없이 흉내 내면 신뢰만 깎인다.
- 요가니드라 정식(61포인트·결심·깨어남). 잠들라는 포맷에 "깨어 있으라"가 섞인다.
