# 새 채널 컨셉 제안 (2026-09-06, 초안 v1)

근거: [docs/sleep-healing-benchmark.md](./sleep-healing-benchmark.md)
확정된 사용자 방향: **잔잔한 음성 명상 + 백색소음** / **한국 단독 집중** / 음원은 **라이브러리 구독**

---

## 1. 한 줄 정의

> **매일 밤 다른 "장소"로 데려다주는 심상유도 수면 명상 채널.**
> 10분 나레이션으로 그곳에 눕히고, 그곳의 소리로 밤을 채운다.

에일린의 **톤**(잔잔한 음성 명상 + 장시간 사운드) 위에,
브레이너 제이의 **컨셉 축**(매 편이 다른 이유)과
힐링트리의 **비주얼 브랜딩**(글자 없이도 식별되는 일러스트)을 얹는다.

## 2. 왜 이 컨셉인가 — 벤치마크가 시킨 것

| 벤치마크 교훈 | 이 컨셉의 대응 |
|---|---|
| 볼륨 전략은 2024년부터 붕괴 (H&S 2026년 10만+ 0편) | 주 2~3편, 편당 완성도에 자원 집중 |
| 1편 = 1작품이어야 카니발라이즈 안 됨 | **매 편 고유 장소명**이 제목·썸네일·사운드를 전부 결정 |
| 차별화 축이 "음악"이면 진입장벽 0 | 축을 **심상(장소) 대본**으로 옮김 — 대본은 복제가 어렵다 |
| "짧은 나레이션 + 장시간 사운드"가 명상 단독 대비 1.7배 | 이 결합을 기본 포맷으로 고정 |
| 에일린 IP의 본체는 실존 강사의 얼굴·목소리 | 우리는 **일관된 목소리 + 세계관**으로 그 자리를 채움 |
| 유튜브 광고만으로는 니치 수익이 약함 | 처음부터 확장 경로 설계(§8) |

**핵심**: 우리가 이미 가진 자산(대본 집필 파이프라인 · AI 이미지 · 화풍 앵커 · TTS ·
CapCut 자동 드래프트 · 업로드 자동화 · `sleep_noise_*.mp3`)이 그대로 맞물리는 유일한 방향이다.
순수 수면음악으로 가면 우리 자산 대부분이 놀고, 승부처가 "작곡 실력"으로 넘어간다.

## 3. 영상 포맷 (고정 규격)

```
0:00 ─ 0:40   도입   "편한 자세로 누우세요" + 오늘 갈 장소 한 문장 예고
0:40 ─ 10:00  심상유도 나레이션 (호흡 → 몸 이완 → 장소 도착 → 감각 묘사 → 놓아주기)
              배경: 그 장소의 앰비언스 + 아주 낮은 패드
10:00 ─ 끝    나레이션 종료. 앰비언스/백색소음만 남는다.
              화면은 5~8분에 걸쳐 서서히 암전 (H&S의 "5분 후 화면 꺼짐"을 계승, 단 급격히 끄지 않음)
```
- **길이 라인업**: 본편 **8시간** 기본. 같은 소재로 **30분판**(명상 단독)을 따로 낸다.
  → 힐링트리의 "1곡 3편 재편성" 응용. 30분판은 검색·짧은 낮잠 수요, 8시간판은 밤 재생 수요.
- **화면**: 정지 일러스트 1장 + 아주 느린 Ken Burns. 이미 `capcut.ken_burns` 설정 자산 있음.
- **자막**: 넣지 않는다(눈을 감게 하는 게 목적). 대신 설명란에 대본 요약.
- **카테고리: Howto & Style** — 에일린과 동일. Music 카테고리 회피.
- **태그: 비움.** 에일린처럼 제목 키워드로만 검색을 먹는다.

## 4. 소재 = "장소" 라인업 (초기 12편 안)

한국인이 정서적으로 아는 장소를 우선한다. 각 장소가 사운드·일러스트·대본을 동시에 규정한다.

| # | 장소 | 사운드 축 |
|---|---|---|
| 1 | 비 오는 산사 처마 밑 | 빗소리 + 낙수 + 먼 풍경(風磬) |
| 2 | 한밤의 대숲 | 댓잎 스치는 바람 |
| 3 | 눈 내리는 시골집 아랫목 | 장작 타는 소리 + 눈 밟는 정적 |
| 4 | 새벽 바다 앞 민박방 | 파도 + 창틀 바람 |
| 5 | 여름밤 시골 마루 | 풀벌레 + 모기장 + 먼 개 짖는 소리 |
| 6 | 안개 낀 새벽 호수의 나룻배 | 물결 + 노 젓는 소리 |
| 7 | 늦은 밤 달리는 완행열차 | 레일 규칙음 + 객실 정적 |
| 8 | 오래된 도서관 열람실 | 종이 넘김 + 형광등 험 + 빗소리 |
| 9 | 첫눈 오는 밤의 온돌방 | 백색소음 + 눈 |
| 10 | 계곡 옆 텐트 안 | 계곡물 + 텐트 천 흔들림 |
| 11 | 늦가을 감나무 있는 마당 | 바람 + 낙엽 |
| 12 | 잠 못 드는 도시의 창가 (비) | 도시 빗소리 + 먼 차 소리 |

→ 야담 채널의 조선·한옥 화풍 자산과 세계관이 겹친다. 같은 미술 방향을 재활용할 수 있다.

## 5. 제목 공식

```
[N분 만에 잠드는] [장소] 수면 명상 | [N시간] [사운드], 불면증, 잠잘때 듣는 명상
```
예)
- `10분 만에 잠드는 비 오는 산사 수면 명상 | 8시간 빗소리 백색소음, 불면증, 잠잘때 듣는 명상`
- `눈 내리는 시골집 아랫목 수면 명상 | 8시간 장작 소리, 수면유도, 잠잘때 듣는 명상`

앞은 **고유 컨셉**(브레이너 제이), 뒤는 **검색 키워드 꼬리**(에일린·H&S 공통).
"떡실신 / 기절" 같은 자극 카피는 쓰지 않는다 — 톤이 컨셉의 일부다.

## 6. 썸네일 규격

- **어둡고 저채도** 일러스트 1장(그 장소의 밤). 밝기 상한을 두어 밤에 눈이 부시지 않게.
- 텍스트는 화면의 **30~40%만**, **얇은 명조 계열** 흰 글씨 **2줄** + 포인트 1색.
- 카피는 시적으로. (`오늘 밤은, 비 오는 산사에서.` / `10분이면 됩니다. 눈 뜨면 아침입니다.`)
- 화면 어딘가에 **누운 사람 또는 이불의 실루엣** — "지금 누워서 트는 것"이라는 상황을 전달.
- 시리즈 식별자: 좌하단에 항상 같은 위치·같은 크기의 채널 워드마크.

## 7. 채널명 · 프로필 후보

### 평가 기준
1. **컨셉 설명력** — 이름만 듣고 "매 편 다른 곳으로 데려가 준다"가 전달되는가
2. **검색 충돌** — 기존 대형 채널·일반 검색어와 부딪히지 않는가 (「힐링」·「수면음악」류는 이미 포화)
3. **발음·기억** — 3~5자, 한 번 듣고 따라 말할 수 있는가
4. **톤 일치** — 조용하고 따뜻한가. 자극적·밈성 이름은 컨셉을 깬다
5. **확장성** — 나중에 명상 외 포맷(수면 이야기·앰비언스 단독)을 얹어도 이름이 안 좁아지는가

### A. 장소·여행 결 — 컨셉을 이름이 직접 설명한다

| 후보 | 뜻 | 평가 |
|---|---|---|
| **밤마실** | 밤에 마실 나가다 (순우리말) | ★최선. 3자, 순우리말, 따뜻함. "매일 밤 다른 곳에 다녀온다"가 그대로 담긴다. 검색 충돌 거의 없음. 프로필·워드마크로 만들기도 쉽다 |
| **잠결여행** | 잠결에 떠나는 여행 | 컨셉 설명력 1위. 다만 4자에 한자어라 「밤마실」보다 덜 부드럽다 |
| **잠의 지도** | 매 편이 지도 위의 한 지점 | 시리즈 구조를 이름이 설명. 12편·24편 쌓일수록 힘이 붙는다. 조금 관념적 |
| **밤의 처마** | 1번 소재(비 오는 산사 처마)에서 | 아름답지만 「처마」에 갇혀 확장성이 낮다 |

### B. 잠·자리 결 — 사용 상황을 이름이 말한다

| 후보 | 뜻 | 평가 |
|---|---|---|
| **베갯머리** | 베개 맡, 잠자리 곁 | ★차선. 순우리말, 잠과 직결, "머리맡에서 들려준다"는 화자 위치까지 담긴다. 확장성도 넓다 |
| **자리끼** | 밤에 머리맡에 두는 물 | 정서적으로 아름답지만 **뜻을 모르는 사람이 많다** — 첫 접촉에서 손해 |
| **눕는 밤** | — | 담백하고 상황이 그려진다. 다소 밋밋 |
| **오늘 밤, 여기서** | 매 편 장소가 바뀌는 구조 | 설명력은 좋으나 길고 검색 친화성이 낮다 |

### C. 고요·밤 결 — 톤을 이름이 말한다

| 후보 | 뜻 | 평가 |
|---|---|---|
| **고요방** | 고요한 방 | 짧고 기억됨. 다만 「여행」 컨셉이 안 드러난다 |
| **밤의 결** | 밤의 결(texture) | 가장 조용하고 고급스러움. 추상적이라 첫 접촉 전달력이 약함 |
| **달빛방** | — | 예쁘지만 흔한 조합이라 검색에서 묻힌다 |
| **새벽 세시** | 불면의 시각 | 불면 타깃 소구가 강하지만 **불면의 괴로움**을 환기시켜 톤과 어긋난다 |

### 피할 이름
- **「스르르」류** — Healing & Silent가 제목에 도배하는 단어라 검색이 그쪽으로 빨린다
- **「힐링」·「수면음악」 포함** — 포화 키워드. 채널명이 아니라 검색어가 된다
- **영문 혼용(Sleep Trip 등)** — 한국 단독 집중이면 한글이 유리
- **밈성 이름** — 톤이 컨셉의 일부다

### 추천
**1순위 「밤마실」 / 2순위 「베갯머리」.**
둘 다 순우리말이고, 3~4자이고, 컨셉(데려간다 / 머리맡에서 들려준다)을 이름이 설명한다.

- 프로필 이미지: 어두운 배경에 달·창·이불 중 하나를 최소한의 선으로. 저채도, 워드마크 병기.
- 배너: 시리즈 장소 3~4곳을 가로로 이은 야경 일러스트 + 한 줄 카피.
- 채널 소개: 포맷을 그대로 밝힌다(에일린 방식). "10분 명상 가이드 + N시간 백색소음으로 구성됩니다."
- **의료 면책조항 고정 문구 필수.**

## 8. 수익·확장 설계 (처음부터 깔아둔다)

유튜브 광고만 보면 이 니치는 불리하다(음악 카테고리 CPM ≈ $1.4대, 장시간 영상 완주율 낮음).
- Howto & Style 카테고리 사용으로 CPM 열위를 일부 완화
- 멤버십: 광고 없는 원본 음원 / 장소 신청권
- 사운드팩·앰비언스 음원 판매(직접 제작분에 한함 → 우리 권리)
- 앱·PDF(수면 루틴) 등 에일린이 검증한 경로

## 9. 리스크와 대응

| 리스크 | 대응 |
|---|---|
| **목소리** — 명상 나레이션은 숨소리·정적이 품질의 본체다. TTS가 어색하면 컨셉 전체가 죽는다 | **1편 제작 전 목소리 테스트를 먼저 한다.** §10 참조 — 이게 최우선 결정 |
| 재사용/대량생산 판정 | 주 2~3편 상한, 매 편 고유 대본·고유 일러스트·고유 사운드 믹스 |
| Content ID 클레임 | 구독 라이브러리 사용 + 다운로드 증빙 보관, 업로드 전 Studio 저작권 검사 |
| 니치 전체 압축(에일린·힐링트리 최신편도 하락 중) | 검색 수요(에버그린) 중심 설계 — 초기 12편을 검색어 커버리지로 배치 |
| 의료 효능 오인 | 면책조항 고정, "치료" 표현 금지 |
