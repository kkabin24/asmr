# 수면 채널 다양화 전략 + 「중간광고 없음」 실태 (2026-09-21)

질문 두 개에 답한다. ① 비슷한 영상을 반복 올리면 수익화가 막히는데 어떻게 다양화할 것인가. ② 벤치 채널들은 「중간광고 없음」을 얼마나 쓰는가.
데이터: 벤치 6채널 전체 카탈로그 3,190편(`yt-dlp --flat-playlist`) + 상위 107편 전체 메타(설명란·태그·챕터). 원자료 `channels/sleep/research/`.

## 1. 정책 — 정확히 무엇이 걸리는가

YouTube 채널 수익 창출 정책(2025-07-15 개정)에서 종전 「반복적인 콘텐츠」가 **「진정성 없는 콘텐츠(inauthentic content)」**로 이름이 바뀌었다. 새 규제가 아니라 **명확화**다 — 기존에도 있었고, 대량 생산·템플릿 반복을 더 분명히 겨눈 것.

공식 문서의 「해당함」 예시 (원문 요지):
- 교육적 가치·해설·서사가 낮고 **변화가 최소한**인 유사·반복 콘텐츠
- 같은 상황을 반복하는 캐릭터 / 이미지 슬라이드쇼 / 템플릿 스토리 / 서사 없는 스크롤 텍스트
- **일반적·비독창적 템플릿으로 만든 AI 생성 콘텐츠**로 대량 생산 인상을 주는 것

「해당하지 않음」 예시:
- 인트로·아웃트로는 같아도 **본편이 실질적으로 다른** 영상
- 회차마다 줄거리가 다른 시리즈

★ 우리 포맷의 위험 요소를 그대로 대입하면: **TTS 목소리 + 정지 사진 한 장 + 같은 백색소음 + 같은 대본 뼈대**를 매주 올리는 것이 정책이 묘사한 "템플릿 + 최소 변화 + 대량 생산 인상"과 정확히 겹친다. 수면 장르가 문제가 아니라 **카탈로그 전체가 한 얼굴**인 게 문제다. (한국 언론의 "사람 목소리만 수익화" 식 보도는 공식 문서에 없는 과장이다. 공식 기준은 *독창성·저자의 기여·실질적 변화*다.)

¹ 무작위 두 제목의 3-gram 자카드 평균. 0.48 = 아무 두 편을 골라도 제목의 절반이 같다. ² 길이 변동계수(표준편차/평균).

힐링앤사일런트는 제목이 서로 절반씩 겹치고 길이가 전부 9시간이다. 브레이너는 234편 중 같은 제목이 하나도 없고 길이가 15분에서 9시간까지 흩어져 있다. **제목 유사도 0.01 vs 0.48 = 조회 중앙값 43배 차이.** 다양화는 정책 방어가 아니라 **성과 그 자체**다.

즉 다섯 축 — **기법 × 무대 × 대상 × 시간구조(길이·알람) × 소리** — 를 조합해 편마다 다른 "오늘 밤의 경험"을 판다. 바디스캔은 그중 한 기법일 뿐이다.

### 2-2. 에일린은 다른 방식 — 수면 편을 거의 안 올린다
381편 중 수면·명상 계열은 **20편**(5%). 나머지는 요가·스트레칭. 수면 20편 중 5편이 100만+.
즉 에일린은 "수면 영상을 많이 올려서" 큰 게 아니라 **드물게 올린 수면 편이 전부 에버그린**이라 큰 것이다. 우리가 수면 단일 채널이면 이 모델은 못 따라간다 → 브레이너 모델(축 조합)이 우리 답이다.

## 3. 우리 채널 다양화 설계

### 3-1. 원칙 세 줄
1. **1편 = 1대본.** 재편성(같은 나레이션에 소리만 늘린 판)은 대본당 최대 1편, 카탈로그의 25% 이하. 연장판은 설명란에 "같은 안내 + 더 긴 소리"라고 밝히고 재생목록으로 묶는다. (종전 bodyscan-study §4-3의 "1h/2h/3h/6h 4편"은 **철회** — 힐링앤사일런트 패턴이다.)
2. **연속 두 편이 아래 다섯 축 중 두 개 이상을 공유하지 않는다.** 이 규칙 하나가 카탈로그를 자동으로 흩뜨린다.
3. **사람의 기여를 눈에 보이게 남긴다.** 대본은 사람이 쓴다(TTS는 낭독만), 정적 타이밍은 손으로 잡는다, 소음은 직접 녹음·생성한다, 설명란에 「제작 노트」(왜 이 순서·이 소리인지 3줄), 챕터, 고정 댓글. 수익화 재검토가 오면 이게 증거다.

### 3-2. 다섯 축 (우리 버전)
| 축 | 값 | 비고 |
|---|---|---|
| **A. 기법** | 바디스캔(머리→발 / 발→머리 / 접촉면) · 호흡 단독(정화·4-7-8·숫자 세기) · 심상 여행 · 자기 위로·확언 · 소리만 | 바디스캔은 6개 중 하나. 카탈로그의 1/3 이하 |
| **B. 상황·대상** | 생각 많은 밤 · 시험 전날 · 교대근무 후 낮잠 · 아픈 날 · 울고 난 밤 · 비 오는 밤 · 여행지 낯선 침대 · 아이 재우고 난 뒤 | 제목의 편익이 여기서 나온다 |
| **C. 시간 구조** | 낮잠 15/25분(알람 有) · 1h · 2h · 3h · 6h(알람 有/無) | 길이마다 대본이 다르다(낮잠은 "깨어나기"가 있다) |
| **D. 소리** | 백색소음 · 빗소리 · 장작 · 기차 · 파도 · 선풍기 · 시냇물 · 무음(나레이션만) | 직접 녹음/생성 → 우리 권리, Content ID 클레임 0 |
| **E. 화면(도입 사진)** | 침실 스탠드 · 비 내리는 창가 · 캠핑 텐트 · 기차 침대칸 · 시골 방 · 호텔 · 병실 창가 | 실사·누운 사람·좌 45% 여백은 고정, **장소만 바꾼다** |

### 3-4. 대본 수준의 다양화 (같은 기법이라도)
- 순서를 바꾼다: 머리→발 / 발→머리 / 접촉면→중심 / 좌우 교차(요가니드라식은 ✕).
- 은유를 바꾼다: 침대에 녹아든다 / 물 위에 뜬다 / 모래에 자국이 남는다 / 눈 위에 눕는다.
- 마음 구간의 소재를 바꾼다: 하루 정리 / 걱정 거리두기 / 감사 / 내일 할 일 내려놓기.
- 끝을 바꾼다: 확언 3개 / 자기 위로만 / 소리로 사라짐 / (낮잠) 깨어나기 카운트.
→ 대본 파일명에 축을 박는다: `templates/bodyscan_v2.md`, `breath_count_v1.md`, `nap25_v1.md`, `imagery_train_v1.md`.

### 3-5. 채널 운영 신호
- 재생목록을 축 B(상황)로 만든다: 「생각 많은 밤」「낮잠」「여행지에서」「아픈 날」. 유튜브가 시리즈로 읽는다.
- 커뮤니티 탭: 다음 무대 투표, 소음 녹음 현장 사진. "사람이 운영한다"는 신호.
- 쇼츠 1~2분: "바디스캔이 왜 잠이 오게 하나" 같은 해설 — 저자의 기여가 드러나는 가장 싼 방법. 브레이너의 「수면과학 해설」 축.
- 하지 말 것: 매일 업로드, 같은 썸네일 레이아웃에 글자만 교체, 대본 문장 순서만 바꾼 "신작".

## 4. 「중간광고 없음」 — 벤치 채널 실태

### 4-1. 데이터
| 채널 | 카탈로그 | **제목**에 「중간광고 없음/광고 없어요」 | 설명란(상위 편) |
|---|---:|---:|---:|
| 힐링앤사일런트 | 1,622 | **132편 (8%)** | 12편 중 0 |
| 요가소년 | 637 | 5편 (1%) — 플레이리스트 편만 | 10편 중 0 |
| 에일린 | 381 | 1편 (0.3%) — 명상음악 편 | 19편 중 0 |
| 브레이너 제이 | 234 | 1편 (0.4%) — 고래 소리 편 | 20편 중 0 |
| 김주환 / 명상하는그녀 | 113 / 203 | 0 | 0 |
| 영어 상위 16편 | — | 0 | 0 |

**결론: 「중간광고 없음」은 힐링앤사일런트 한 채널의 문구다.** 그마저 제목 8%뿐이고, 상위 나레이션 채널은 사실상 쓰지 않는다. 쓰는 채널(중앙값 5,700)과 안 쓰는 채널(중앙값 15만~24만)의 성과를 보면 이 문구가 조회를 만들지는 않는다. 음악만 트는 채널이 "볼륨 경쟁"에서 내세운 궁여지책에 가깝다.

### 4-2. 우리 결정
- **광고 설정**: 미드롤은 끈다(수면 콘텐츠에서 광고가 사람을 깨우면 리텐션·좋아요·재방문이 다 깎인다). 프리롤·포스트롤만.
- **말하지 않는다**: 제목·썸네일에 넣지 않는다(벤치가 안 쓴다, 자극 카피 톤에 가깝다). 설명란 제작 노트 한 줄("중간 광고 없이 편성했습니다")은 괜찮다.
- **수익 관점**: 이 장르 수익의 큰 몫은 광고가 아니라 **YouTube Premium 시청 시간 배분**이다(프리미엄 회원의 시청 시간 비례). 2시간을 틀어 놓는 시청자가 많을수록 미드롤 없이도 수익이 난다. 그러니 미드롤을 끄는 게 손해가 아니다.
