# 백색소음 음원 (사용자 보유분을 여기에)

렌더 스크립트(`scripts/render/sleep_render.py`)가 이 폴더의 음원을 나레이션 뒤에 얹어 2시간을 채운다.

## 파일 규칙
- 형식: mp3 / wav / m4a 아무거나. 스테레오 권장.
- 이름: 내용을 알 수 있게. 예) `rain_soft.mp3`, `fan.mp3`, `brown_noise.mp3`, `waves.mp3`
- 길이: **10분 이상**이면 된다 — 부족하면 스크립트가 끊김 없이 루프한다.
  루프 시 이음새가 티 나지 않게, 시작과 끝이 같은 소리(페이드 없음)인 음원이 좋다.
- 라우드니스는 신경 쓰지 않아도 된다 — 렌더 때 나레이션보다 6dB 낮게 자동 정규화.
