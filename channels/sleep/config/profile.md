# 채널 프로필: (미정 — 밤마실 / 베갯머리)

## 포맷 (벤치마크 에일린 mind yoga 를 따른다)
**바디스캔 수면명상 나레이션(10~12분) + 백색소음(나머지)** = 완성본 **2시간**.
화면은 도입부 **실사 사진 한 장**뿐이다. 어둡게 시작해 3분에 걸쳐 검정으로 페이드아웃, 이후 끝까지 검정.
눈을 감게 하는 콘텐츠라 그림은 "지금 누워서 트는 것"이라는 상황만 전달하면 된다.

## 화면
- **실사 사진**(일러스트 ✕). 어둡고 따뜻한 침실, 스탠드 하나. **반듯이 누운 실제 사람** 또는 펴 둔 이부자리.
- 썸네일 = 도입 이미지. 문구는 사람이 얹으므로 이미지에 글자 없음, 좌 45% 비움.

## 말투
- 낮고 느린 **존댓말** 2인칭 안내 ("~합니다 / ~봅니다 / ~해 보세요").
- 핵심 동사: **알아차립니다 → 내쉬는 숨에 긴장을 침대로 내려놓습니다**. 이 한 쌍이 바디스캔의 리듬이다.
- 판단 없음. "잘하는 호흡, 못하는 호흡은 없어요."
- 자기 위로 구간만 반말 허용 ("수고했어. 잘했어.").
- 문장 사이 **정적 5~15초**. 여백이 콘텐츠다.

## 금지
- 서사·반전·캐릭터. 정보 강의. 자극 카피("떡실신", "기절").
- "치료" 표현. 의료 면책조항 고정.

## 업로드 규칙 (2026-09-20, 근거: docs/bodyscan-study.md §2~§4)
- **제목**: `[편익+시간] + 수면유도 명상 | 수면명상, 수면유도음악 N시간, 바디스캔 명상`
  예) `10분 안에 잠드는 꿀잠 수면유도 명상 | 수면명상, 수면유도음악 2시간, 바디스캔 명상`
  ★「바디스캔」은 절대 제목 앞에 두지 않는다 (제목 앞 바디스캔 편 중앙값 7천 vs 없는 편 32만). 기법명은 꼬리 키워드.
- **카테고리** Howto & Style. **태그** 비움(상위 34편에서 태그 수와 조회 무관).
- **챕터**(설명란 타임라인 필수): `00:00 시작` / `00:30 수면 안내 (약 12분)` / `12:xx 백색소음 시작` / `03:30 화면 검정` / 마지막 줄 `기상 알람 없음 — 알람은 따로 맞춰 주세요`
- **설명란 순서**: ① 구성을 숫자로 ("12분 수면 안내 + 1시간 48분 백색소음") ② 권장 대상 2~3줄 ③ "애써 잠을 자려 하지 않을수록 잠에 가까워집니다" ④ 의료 면책조항 ⑤ 음원 크레딧
- **썸네일 카피**: 「편익+시간」 1줄 + 「수면 명상」 1줄, 얇은 명조, 좌 45%. 예: `10분이면 됩니다. / 눈 뜨면 아침이에요.` 자극 카피·권위 뱃지·굵은 컬러 텍스트 ✕.
- **길이 다변화**: 같은 나레이션으로 1h / 2h / 3h / 6h 재편성 = 신규 제작 없이 4편.
